# 📈 Stock & Commodity News Intelligence Agent

A fully automated, AI-powered market intelligence system that delivers daily actionable insights about stocks and commodities — powered by news analysis, not technical charts.

## 🌟 Features

- **🤖 AI-Powered Analysis**: Uses Google Gemini to analyze 50-100 news items daily and surface the top 4-5 market-moving insights
- **📰 Multi-Source Collection**: Aggregates from Google News, financial RSS feeds (MoneyControl, ET, Reuters), Twitter/X, and Reddit
- **📊 Beautiful Dashboard**: Premium dark-mode website with glassmorphism design, auto-updated daily
- **📅 Historical Archive**: Browse past reports with a date picker
- **⏰ Fully Automated**: Runs every morning at 8:00 AM IST via GitHub Actions
- **💰 100% Free**: No paid APIs, no hosting costs

## 🏗️ Architecture

```
GitHub Actions (8 AM IST) → Python Collectors → Gemini AI Analysis → Static Site → GitHub Pages
```

## 🚀 Quick Setup (5 minutes)

### 1. Fork & Clone

```bash
git clone https://github.com/YOUR_USERNAME/StockPriceNews.git
cd StockPriceNews
```

### 2. Get Your Gemini API Key (Free)

1. Go to [Google AI Studio](https://aistudio.google.com/)
2. Click **"Get API Key"**
3. Create a new API key (no credit card required)
4. Copy the key

### 3. Add GitHub Secrets

1. Go to your repo → **Settings** → **Secrets and variables** → **Actions**
2. Click **"New repository secret"**
3. Add: `GEMINI_API_KEY` = your API key from step 2

### 4. Enable GitHub Pages

1. Go to repo → **Settings** → **Pages**
2. Set Source to **"Deploy from a branch"**
3. Set Branch to **"gh-pages"** and folder to **"/ (root)"**
4. Click **Save**

### 5. Run It!

- **Manual run**: Go to **Actions** tab → **"Daily Market Intelligence"** → **"Run workflow"**
- **Automatic**: It will run every day at 8:00 AM IST automatically

Your site will be live at: `https://YOUR_USERNAME.github.io/StockPriceNews/`

## 🏃 Run Locally

```bash
# 1. Start the React Frontend
cd web
npm install
npm run dev
# The dashboard will run at http://localhost:5173

# 2. Run the Python Agent (in another terminal)
cd ..
python -m venv venv
venv\Scripts\activate      # Windows
# source venv/bin/activate  # Mac/Linux

pip install -r requirements.txt
copy .env.example .env
# Edit .env and add your GEMINI_API_KEY

python -m src.main
# Refresh the browser to see the latest insights!
```

